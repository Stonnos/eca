## ECA
Версия: 7.1
Дата релиза: 29.10.2025

## Запуск программы для Windows

Запуск программы осуществляется с помощью exe файла ECA.exe

## Запуск программы для Linux

Запуск программы осуществляется с помощью команды sh eca.sh

## Дополнительно

Для увеличения максимального размера оперативной памяти для программы необходимо в файле jvm.options изменить параметр -Xmx, например -Xmx4096m.
